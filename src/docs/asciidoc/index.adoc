== 판매품목

* 주문 전에 SKU를 등록하고 응답의 UUID로 조회·판매 중단을 요청합니다.
* 판매 중단 상태는 DISCONTINUED이며 반복 중단은 같은 상태를 반환합니다.
* 판매 중단으로 기존 주문·재고가 바뀐다고 가정하지 않습니다.

== 주문

* 판매 중인 Offer의 SKU를 서로 다르게 1~10개 제출하고 품목별 수량은 1~100으로 지정합니다.
* 품목(OrderLine)은 접수 후 변경하지 않습니다. 접수 상태는 PLACED, 취소 상태는 CANCELLED이며 반복 취소는 같은 상태를 반환합니다.
* Offer 조회 직후 판매 중단이 커밋된 경우에는 이미 읽은 상태로 주문이 접수될 수 있음을 고려합니다.
* 주문 성공으로 재고 확인·예약을 가정하지 않습니다.
