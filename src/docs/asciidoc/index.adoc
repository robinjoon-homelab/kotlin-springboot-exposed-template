== 판매품목

주문 BC의 Offer 어그리게이트입니다. SKU는 유일하며, UUID로 조회하고 판매를 중단합니다.
판매 상태는 ON_SALE에서 DISCONTINUED로 바뀌며 반복 중단은 같은 상태를 반환합니다.
판매 중단은 이미 접수한 주문을 바꾸지 않습니다. 재고 등록과도 독립적입니다.

== 주문

주문 BC의 Order 어그리게이트입니다. SKU가 서로 다른 품목 1~10개, 품목별 수량 1~100을 받습니다.
품목(OrderLine)은 주문이 함께 저장하는 값 객체이며 접수 후 변경하지 않습니다. 주문은 PLACED 상태로 접수됩니다.
Offer를 읽은 시점에 모든 SKU가 ON_SALE이어야 합니다. 조회 직후 판매 중단이 커밋돼도 읽은 상태로 접수할 수 있습니다.
취소하면 CANCELLED가 되고, 반복해서 취소해도 같은 상태를 반환합니다.
주문은 재고를 확인하거나 예약하지 않습니다.
